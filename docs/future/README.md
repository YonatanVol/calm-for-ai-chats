# Not shipped

These files describe a **possible future** paid tier (accounts, cross-device
sync, billing). They are kept for reference only.

The shipped extension has **no account, no sync, no permissions and no network
code** — see `PRIVACY.md`. Nothing in this folder is part of the build; the
packaged zip contains only `manifest.json`, `src/`, `content.css` and `icons/`
(see `install.py`).

Anything here would require a new privacy review and a new store submission
before it could ship, and the privacy policy would have to change first.
